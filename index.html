P-02 Private Google Drive Backup Tools

This is an informational website for two owner-operated Google Drive backup integrations supporting a private mineral exploration research project. These are personal-use tools, not public services. The website does not request Google sign-in, receive Drive files, or collect OAuth tokens.

P02 Rclone Backup

The existing integration uses the open-source rclone utility to transfer or back up files between the owner's computer and the owner's Google Drive as directed by the owner. Its authorization is separate from the Python integration.

P02 Private Alaska Archive

A separate Python backup integration runs on a GitHub-hosted Actions runner, when manually authorized by the owner. It uses the Google Drive API to create, inspect, and verify backups in the owner's Google Drive. It requests the https://www.googleapis.com/auth/drive.file scope, limited to files created by or made accessible to the application.

The connection check uses a small synthetic test file. Acquisition and archiving of public Alaska mineral-tenure GIS snapshots is a separate owner-authorized operation. The files and authentication credentials are not published in the website's repository.
