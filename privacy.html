Privacy Policy - P-02 Private Google Drive Backup Tools

These applications are personal-use tools controlled by the Google account owner, not a public service. This website is an informational page and does not ask visitors to sign in to Google or submit personal information.

Applications and Google Drive access

P02 Rclone Backup: The owner uses the open-source rclone utility to transfer, list, verify, and manage selected files between the owner's computer and Google Drive. Access is limited by the permissions granted to that separate rclone OAuth client and by the owner's instructions.

P02 Private Alaska Archive: The owner uses a Python application executed through private, manually triggered GitHub Actions workflows. It requests the Google Drive https://www.googleapis.com/auth/drive.file permission to create and verify backup files that the application creates or that are made accessible to it. It can create an archive folder and upload, inspect, or delete its own test and backup files.

What information is processed

The applications process the selected backup files and the Google Drive metadata needed to identify, upload, verify, retrieve, or delete those files. The Alaska archive may contain downloaded public mineral-tenure GIS source data, quality-control records, manifests, and checksums. The informational website itself does not receive Google Drive file contents or OAuth tokens.

Where information is stored

Rclone's authorization configuration is stored on the owner's device. The Python application's OAuth credentials are intended to be held in private GitHub Actions repository secrets and used only during authorized workflow runs. During an authorized run, the Python application processes files on the GitHub-hosted runner before transferring selected results to the owner's Google Drive. The backup contents are not committed to the public website repository. Google and GitHub may process information as needed to provide their respective services.

Use and sharing

The applications use Google Drive information only to perform owner-directed backup, verification, retrieval, and cleanup operations. They are not used for advertising, profiling, or sale of user data. No Google Drive user data is intentionally shared with advertisers or made public by the website. Data is disclosed only as necessary to the connected service providers and as directed by the owner.

Retention and deletion

Stored backup files remain in the owner's Google Drive until the owner deletes them or authorizes their deletion. A successful Python connection smoke test creates a temporary synthetic file, verifies it, and then removes it; a failed test may require manual cleanup. Temporary runner storage is not intended as a permanent archive. The owner can delete stored files in Google Drive and revoke each application's authorization in Google Account security settings.

Security

OAuth permissions are granted by the owner. Tokens are not embedded in this public website. The Python workflow is intended to be run only through a private repository with owner-controlled GitHub Actions secrets. Authorization can be revoked by the Google account owner at any time.
