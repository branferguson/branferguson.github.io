Privacy Policy

P02 Rclone Backup is a personal-use configuration of the open-source rclone program.

Google Drive Access

The application requests access to the account owner's Google Drive files to list, copy, upload, download, and manage files as instructed by the owner.

Data Storage

File content is transferred between the owner's device and Google Drive. Rclone stores its Google authorization configuration and tokens locally on the owner's computer.

Data Sharing

The application does not sell Google user data or share it with advertisers. This informational GitHub Pages website does not receive Google Drive file contents or authorization tokens.

Security and Access

Access is controlled by the owner's Google authorization and can be revoked through Google Account settings.
